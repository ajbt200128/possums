# Mixed-provider Pi history — source-only verification

The client no longer rejects assistant history solely because its provider or API differs from Possums. It reuses Pi's supported OpenAI message conversion for mixed-model/provider text and function-tool history. Thinking blocks are removed from the conversion input so Pi cannot promote cross-provider thinking into prompt text; original transcript content remains unchanged. Existing image, custom-tool, authenticated catalog, reservation, receipt and live tool-completion constraints remain intact.

Offline regression coverage includes Anthropic messages, OpenAI Responses and a different Possums model: assistant text, tool arguments, matching call/result IDs, absence of thinking/signatures in the request, unchanged input history and one synthetic provider dispatch. No live inference was performed.

Checks used Node 24.13.0 and the existing locked dependency cache in a fresh scratch tree. TypeScript `--noEmit`, extension build and the complete `clients/pi/check.mjs` suite passed. The suite passed against shipped Pi 1.0.4 and current Pi 1.1.0 runtime artifacts. Worktree LSP diagnostics cannot resolve the absent runtime peer dependencies; the pinned scratch typecheck passed. This is client-source qualification, not installation, activation, gateway deployment or proof of every upstream model's acceptance.

Adjacent guard review: `clients/pi/wire.ts` still blocks images, custom tool namespaces and unsupported constrained sampling. `clients/pi/provider.ts` blocks arbitrary temperature/sampling overrides, output-cap overrides and custom fetch; requires model tool qualification from the authenticated catalog; and binds the selected provider/API/endpoint. Sampling overrides are a remaining conservative capability restriction. Images and custom tool formats are outside the current text/OpenAI-function contract; output allowance, verified transport, catalog qualification and completion/accounting evidence have separate product/security requirements and were not weakened.
