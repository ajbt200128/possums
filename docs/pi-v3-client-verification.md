## Trust and transport changes

- Credential-free latest-tag discovery and existing bounded GitHub-to-asset-CDN redirect policy remain acquisition only. Each establishment owns a random 32-byte nonce and acquires `/.well-known/tinfoil-attestation?nonce=<64-lowerhex>` with a v3-specific 16 MiB ceiling; unrelated legacy limits are unchanged. There is no default-path v2 fallback or separate AMD fetch.
- `Channel.v3` snapshots raw evidence, nonce, downloaded manifest and EHBP configuration before appraisal. The private constructor authority is never granted by caller-provided facts/flags. It always sends the exact `repository@tag@sha256:digest` and actual manifest bytes to the disposable Go/WASM Worker. The parent Go ABI authenticates exact subject hash and complete signed predicate JSON value equality with bounded, non-rounding JSON validation. Native appraisal without a manifest remains separate.
- Existing CVM `v0.14.12`, exact config-command-line hash, publisher, denylist and exact 41-byte EHBP constraints remain. Public certificate parsing uses Node's supported X509 implementation; its SPKI must equal the authenticated TLS fingerprint, with native hostname and date validation. Expiry is the minimum of local 12 hours, public leaf expiry and authenticated SDK witness expiry.
- Every v3 Channel request uses the instance-owned TLS-key-bound transport, including bodyless GETs and bearer headers. Node TLS completes and checks the actual peer before constructing/sending HTTP. A fresh socket is used per request, with no proxy, pool, redirects or session resumption. The supported Agent hook returns only that already authenticated socket. Expiry and fixed origin are rechecked at handoff. Endorsed self-signed leaves are accepted through positive peer-SPKI possession/binding, not a Web-PKI bypass without an endorsed key. The pinned SDK's `verify/conformance/live.go` explicitly uses SPKI authority rather than public PKI for this check; its ordinary round-tripper also supports normal PKI, so this is a deliberately scoped client choice, not a claim that every SDK path bypasses PKI.
- Supported Node HTTP, zlib and byte-sized `Readable.toWeb` buffering retain response streaming, decompression, cancellation and backpressure; the queue inherits the native stream's byte high-water mark, not a chunk-count allowance. Supported EHBP encryption/decoder and existing receipt/finish/DONE/EOF/tool gates remain. No inference retry/replay is introduced.
- V3 does not use the legacy disk acquisition cache. Nonce-bound reports, embedded collateral and appraisal verdicts are not persisted. Each establishment reacquires the candidate manifest/evidence; this loses legacy GitHub/AMD warm-cache savings rather than inventing a new cache scheme. Stable in-memory identity is release digest/tag, TLS key and exact EHBP configuration. Recovery compares that tuple plus authenticated freshness: genuinely advancing witnesses can qualify replacement setup even at the same endpoint, only within existing lifecycle permission. Nonce changes or nonadvancing freshness cannot renew authorization, even if raw report bytes differ.
- The elapsed compiled v0.0.15 approval is not rebound, revived or replaced with discovery. Legacy reference factories and pinned decoder/acquisition fixtures remain independently tested. The retained browser reference build replaces the Node-only v3 adapter with a closed trust-policy rejection; it does not substitute legacy verification for a v3 call.
